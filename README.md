# Medical Image Encryption for Advanced Security and Privacy

## Overview
This project implements a chaos-based cryptography algorithm for encrypting medical images. The approach utilizes:

- **1-D Standard Chaotic Logistic Map**
- **2-D Logistic Sine Coupling Map (LSCM)**

These techniques enhance security by leveraging the high sensitivity of chaotic systems, ensuring robust protection of sensitive medical data.

## Features
- **Chaos-Based Encryption:** High security using chaotic maps.
- **Object-Oriented Design:** Implements OOP principles such as inheritance for handling different account types and databases.

## Tools and Technologies
- **Programming Language:** Python
- **Development Environment:** Jupyter Notebook

## Highlights
- Developed an encryption algorithm tailored for medical images.
- Utilized the logistic and sine coupling maps to generate chaotic sequences.
- Ensured strong security through high sensitivity and unpredictability of chaotic systems.
